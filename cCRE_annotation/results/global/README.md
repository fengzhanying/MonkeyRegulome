# Archived global macaque cCRE results

These files were supplied in the local MonkeyRegulome repository. They are
historical analysis outputs, not regenerated biological results from version 1.1.0.
The original data bytes are retained.

| File | Meaning |
| --- | --- |
| monkey_cCREs.bed | Five tab-separated fields: chrom, start, end, id, cCRE_class |
| monkey_cCREs_annotated.txt | Headered full coordinate/score/distance/class table |
| cCRE_class_stats.txt | Six class counts; originally reconstructed from composition CSV, now verified against both coordinate files |
| Monkey_cCRE_Composition_Stats.csv | Readable class labels, counts and proportions |
| Monkey_cCRE_Composition.png | Existing composition image; not regenerated in this validation |
| monkey_cCRE_developmental_annotation.tsv | Optional downstream sample/timepoint/tissue summary, not generated by the global workflow |
| MANIFEST.tsv | Actual file sizes and SHA256 checksums |
| validation_report.json | Internal consistency checks and scope |

The .bed file is a custom BED-like annotation table. Its fifth field is a class
string, not the numeric score required by standard BED5. Use the first four
columns for tools expecting BED4; convert to a proper BED6/9 track for browsers.

Full-table fields:
- id, chr, start, end: stable ID and zero-based, half-open coordinates.
- center_dist: distance to the selected TSS midpoint; 1e12 is a missing-TSS sentinel.
- gene: label of selected TSS; this does not establish enhancer-target regulation.
- tss_core, tss_proximal: inclusive 200 bp and 2000 bp distance flags.
- z_atac, z_h3k4me3, z_h3k27ac, z_ctcf: per-mark maximum z-scores.
- cCRE_class: the ordered six-class assignment.

"Percentage" in the composition CSV is a fraction between 0 and 1.
Multiply by 100 for a percentage display.

Verified total: 702,876 anchors. PLS 8,588; pELS 31,057; dELS 418,047;
CA-H3K4me3 15,357; CA-CTCF 51,837; CA 177,990.

The optional developmental table has 687,576 data rows plus a header. Its IDs
are a unique subset of the global universe; 15,300 global IDs have no row.
Absence is not a measured inactivity call. Its dominant_sample_class describes
sample-level classifications and should not replace the global class.

Recheck with:
~~~bash
python scripts/verify_results.py
~~~

Use --write-manifest only when intentionally refreshing local metadata.
The validation checks stored distances and z-scores, not the correctness of
the original genome assembly, reference annotation or signal extraction.
