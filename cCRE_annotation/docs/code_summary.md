# Code summary

The upload should include the following code files under `cCRE_annotation/scripts/`.

## `run_global_ccre.sh`

Main entry point for the global macaque cCRE workflow. It reads the user-edited
configuration file, creates the working directories, verifies required tools,
builds the bigWig file list, runs signal extraction, and launches downstream
z-score calculation and cCRE classification. On a SLURM cluster it submits array
jobs; otherwise it can run signal extraction serially.

## `00_prepare_masterlist.sh`

Builds the global accessible-anchor universe from the merged macaque ATAC peak
BED file. It normalizes chromosome names, removes non-canonical contigs and
mitochondrial chromosomes, sorts the output, and assigns stable anchor IDs in
the form `chr_start_end`.

Output:

- `$CCRE_WORKDIR/01.masterlist/monkey_rDHS.bed`

## `01_generate_tss.py`

Generates a non-redundant TSS BED file from the Macaca mulatta GTF annotation.
It harmonizes chromosome names against the anchor BED file and deduplicates TSS
records by chromosome, TSS coordinate, and strand.

Output:

- `$CCRE_WORKDIR/01.masterlist/monkey_TSS.bed`

## `02_extract_signals.sh`

Extracts mean signal over each global anchor from one ATAC-seq or CUT&Tag
bigWig file using UCSC `bigWigAverageOverBed`. It is designed to run as a SLURM
array task, using the file list generated by `run_global_ccre.sh`.

Output:

- `$CCRE_WORKDIR/02.signals/*.tab`

## `03_calculate_zscores.py`

Computes per-experiment `log1p(mean0)` z-scores for ATAC, H3K4me3, H3K27ac,
and CTCF. For each mark, it records the maximum z-score across experiments.

Outputs:

- `$CCRE_WORKDIR/03.zscores/ATAC_max_zscore.txt`
- `$CCRE_WORKDIR/03.zscores/H3K4me3_max_zscore.txt`
- `$CCRE_WORKDIR/03.zscores/H3K27ac_max_zscore.txt`
- `$CCRE_WORKDIR/03.zscores/CTCF_max_zscore.txt`

## `04_classify_ccres.py`

Assigns each global accessible anchor to one cCRE class using nearest-TSS
distance and chromatin mark support. The classes are `PLS`, `pELS`, `dELS`,
`CA-H3K4me3`, `CA-CTCF`, and `CA`.

Outputs:

- `$CCRE_WORKDIR/04.classification/monkey_cCREs.bed`
- `$CCRE_WORKDIR/04.classification/monkey_cCREs_annotated.txt`
- `$CCRE_WORKDIR/04.classification/cCRE_class_stats.txt`

## `05_plot_ccre_composition.R`

Optional plotting script that converts the raw class-count table into
publication-friendly labels and writes the cCRE composition figure and summary
CSV.

Outputs:

- `$CCRE_WORKDIR/04.classification/Monkey_cCRE_Composition_Stats.csv`
- `$CCRE_WORKDIR/04.classification/Monkey_cCRE_Composition.pdf`
- `$CCRE_WORKDIR/04.classification/Monkey_cCRE_Composition.png`

## Not included in this global-only release

The following scripts are intentionally excluded from `cCRE_annotation` for the
first release because they are sample-specific, tissue-specific, or downstream
cross-species analyses rather than the global macaque cCRE annotation workflow:

- `05_celltype_specific.py`
- `06_*`
- `07_*`
- `08_*`
- `layer*_liftover.sh`
- `*_3species_*`
- `human_gse63634_*`
